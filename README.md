## Overview

### The challenge

The goal of this challenge was to build a responsive recipe page and
match the provided design as closely as possible.

The page includes:

-   A recipe image
-   Recipe title and description
-   Preparation time information
-   Ingredients
-   Step-by-step cooking instructions
-   A nutrition table

This project was built using only HTML and CSS.

### What I learned

One of the main things I improved while building this project was
working with table spacing and creating a clean nutrition table.

I also learned more about responsive layouts and how to adjust the
design for different screen sizes using media queries.

The nutrition table and the responsive behavior were the parts I was
most proud of in this project.

### Continued development

For my next projects, I want to continue developing my JavaScript skills
and start building projects with React.

My goal is to move from static HTML/CSS projects toward more interactive
and component-based frontend applications.

### AI Collaboration

I used AI as a learning and review tool rather than having it build the
project for me.

-   **ChatGPT** - Used mainly to explain concepts and help me understand
    documentation.
-   **Claude** - Used for code reviews and additional concept
    explanations.
-   Around **90% of the code was written by me**. AI was mainly used to
    review my work, explain concepts, and help me understand areas I was
    unsure about.

This approach helped me learn from the implementation instead of simply
copying generated code.
